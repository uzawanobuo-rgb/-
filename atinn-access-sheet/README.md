# アクセス案内シート作成ツール（アットイン営業用）

お客様に渡す「アクセス案内シート」（A4横1枚）をブラウザだけで作るツールです。
インストールもログインも要りません。URLを開けば誰でも使えます。

- **パターン1：物件 → 主要駅**：物件から新宿・渋谷・品川などの主要駅への所要時間と、1か月／3か月の総額
- **パターン2：目的地 → 2〜5物件**：勤務先などの目的地から各物件への所要時間と総額。「＋ 物件を追加」で最大5つ。4・5件目は地図の右側にカードを重ねて置く（4件は右下、5件は右の列）
  - 「2ページ目に設備比較の表を付ける」にチェックすると、物件ごとの住所・最寄駅・所要時間・総額・建物・設備（✓）の比較表を2ページ目に付ける（PDF・印刷は2ページ、PNGは「…_設備比較.png」の2枚）

仕様は [`docs/SPEC.md`](docs/SPEC.md)、完成見本は [`reference/`](reference/) にあります。

## 使い方

1. `index.html` を開きます（公開URLは下の「公開のしかた」を参照）。
2. 初回だけ、画面の「使い方・ブックマークレット」の黒いボタン **「プラン取込」「乗換取込」** の2つをブックマークバーにドラッグします。
3. アットインの**プランページ**（`https://atinn.jp/plan/…`）で「プラン取込」をクリックします。ツールのタブが開く（ブラウザが許せば、開いているツールのタブに切り替わる）ので、入れる物件（A〜C）を選びます。パターン1はそのまま入ります。物件名・住所・地図座標・最寄駅・料金・写真が入ります。
   - 新しいタブで開いたときは、いまの入力を引き継ぎ、古いツールのタブには「閉じてください」と表示します。
4. ツールが開かないとき（ポップアップが止められたときなど）は、コピーはされているので、ツールの画面で Ctrl+V（または物件の欄の「コピーした物件を読み込む」）で入れます。
5. **所要時間を入れます。** 各駅の枠の「Yahoo!乗換案内で検索」を押し、開いた検索結果のページでブックマーク **「乗換取込」** を押します。乗車時間・乗換回数・路線・乗換駅・出典URLが**自動でツールの枠に入り**、Yahoo!のタブは閉じます（表示された経路のうち乗車時間がいちばん短いもの）。自動で入らないときもコピーはされているので、枠の「コピーした経路を読み込む」を押します。検索は平日10時発・有料特急なしで開きます。
   - 2つのブックマークは本体（`js/bm-atinn.js`・`js/bm-transit.js`）を公開ページから読み込むだけなので、本体を直しても登録し直す必要はありません。
6. メールで送る見積りは、いちばん下の「メール用テキスト」を開いて「コピー」し、メール本文に貼ります（見積りExcel【一般用】と同じ書式・計算。パターン2は入力した利用期間、パターン1は1か月プランの期間。2名以上は1名1,100円/日のオプション料金を足します）。
7. 右のプレビューを確認し、見出し・タグ・数字を必要なら直して、**PNG／PDF** で保存します。
8. 「データ保存」で入力内容をJSONに保存できます。「データ読込」で同じ条件から作り直せます。

入力内容は、このブラウザに自動で保存されます（別のPCや別のブラウザには引き継がれません）。

### 取り込みがうまくいかないとき
- ブックマークレットが使えないときは、プランページで **Ctrl+A → Ctrl+C** してそのまま貼り付けても、料金・最寄駅などは読み取れます。写真と座標は取れないので、座標は「住所から座標を検索」で入れます。
- 取れなかった項目は、確認欄に手で入力できます。取込値から直した料金欄は黄色になります。

## 計算ルール
- 日数＝チェックアウト日 − チェックイン日 ＋ 1（両端を含む）
- 1日あたり＝キャンペーン価格（あれば）、なければ利用料。清掃費も同じ。
- 住宅保険＝1か月あたり × 月数。月数は応当日で数えます（翌月同日の前日までが1か月。はみ出したら次の月）。
- 総額＝利用料合計＋清掃費＋住宅保険。
- 所要時間＝物件から駅までの徒歩＋乗車時間（乗換の歩き・待ちを含む。改札やホームでの最初の待ち時間は含めない）。
- パターン1は、30分以内の主要駅を短い順に最大3つ載せます。

## 路線図
- 方角は正確、距離は中心の近くを拡大（`r' = a × r^0.74`）。どちらが遠いかの順序は保たれます。
- 線は縦・横・45度だけで描きます。山手線の輪を目印として描き、山手線に乗る区間はルートの色で上書きします。
- 駅の座標は `js/data.js` に主な駅を収録しています。ない駅は自動で駅データ（HeartRails Express）を検索し、見つからなければ「座標を入力」から入れます。
- ランドマークは `js/icons.js` の自作イラストです（鉄道会社のラインカラーやロゴ、地図タイルは使っていません）。

## 公開のしかた（GitHub Pages）
1. GitHub のリポジトリで **Settings → Pages** を開きます。
2. 「Build and deployment」の Source を **Deploy from a branch** にし、公開するブランチと `/ (root)` を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/atinn-access-sheet/` で開けます。

サーバー側の処理はないので、HTMLとJSを置くだけで動きます。ブラウザは Chrome／Edge の最新版を想定しています。

## 開発
```
node --test atinn-access-sheet/tests/*.test.js
```
- `js/calc.js` 料金・保険月数（`testdata/price_cases.json`, `insurance_months_cases.json` でテスト）
- `js/geo.js` 座標変換・45度化（方位角と距離の順序をテスト）
- `js/parse.js` プランページの読み取り（SPECの料金本文でテスト）
- `js/map.js` 路線図SVG、`js/sheet.js` シート全体、`js/app.js` 画面
- `vendor/` html-to-image（PNG化）、jsPDF（PDF化）

プランページのHTML構造は未確認のため、読み取りは本文テキストから行っています。サイトの表記が変わったら `js/parse.js` とテストを直してください（ブックマークレットは登録し直す必要はありません）。

## 未決定の事項（SPEC §9）
- チェックアウト日＝応当日のときの保険月数は、暫定で「次の月に入る」扱いです。
- 人数追加料金・ペット・子どもの追加料金は未対応です（注記に人数のみ表示）。
- 東京以外のエリアの目印（山手線の代わり）は未対応です。
- 見積もり有効期限は入れていません。

## Claude Code で作るとき（チャットにプランURLを送る方法）
ツールを使わず、Claude Code のセッションにプランURLを送って作ることもできます。
環境のネットワーク設定で `atinn.jp` と `transit.yahoo.co.jp` を許可しておく必要があります。

- 物件情報：プランページを取得して `js/parse.js` で読み取る
- 所要時間：`scripts/yahoo-routes.js` で Yahoo!乗換案内を検索（平日10時発、有料特急なし）し、徒歩＋乗車が最短の経路を選ぶ
- シート：`js/sheet.js` で組み立て、PNG／PDF と、ツールの「データ読込」で開ける JSON を作る
