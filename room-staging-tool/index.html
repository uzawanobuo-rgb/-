空室写真 家具配置＆演出ツール / Gemini画像生成
キー取得
使い方
  1. 元となる部屋の写真をアップロード
  2. 家具を置きたい場所をドラッグで赤枠指定 → 家具の写真をアップロード → 生成（1点ずつ繰り返す）
  3. 全部配置できたら「モデルルームのように演出」でスタイリング
  4. 最後に明るさ・コントラストを調整してダウンロード

APIキーはこのブラウザから直接Googleへ送信されます。サーバーには保存されません。生成結果は元画像と構図が変わる場合があるため、必要に応じてプロンプトを調整して再生成してください。
