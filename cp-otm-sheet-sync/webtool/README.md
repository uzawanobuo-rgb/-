# CP × OTM 同期Webツール（ローカル起動）

## 起動方法

```bash
cd cp-otm-sheet-sync/webtool
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000/ を開いてください。

## 使い方

1. OTMファイル(.xls)とCPファイル(.xlsm)をそれぞれ選択
2. 「同期を実行」をクリック
3. マッチ結果（新規依頼・期間変更・あいまい一致）が一覧表示される
4. 「更新後のファイルをダウンロード」から結果のxlsmを取得

## 仕組み・注意点

- サーバー側（Python/openpyxl）で処理するため、CPファイルのVBAマクロ・条件付き書式・他シート（スペシャル/ロング/CP価格設定シート）はすべて保持されます。ブラウザ完結（JavaScriptのみ）のツールではこれができません。
- ロジックは `../sync_core.py`（CLI版 `sync_cp_otm.py` と共通）を利用しています。マッチング条件や列の対応を変えたい場合はそちらを編集してください。
- このツールはローカルでの利用を想定した簡易サーバーです（`app.run(debug=True)`）。社内サーバー等で常時公開する場合は、本番用WSGIサーバー（gunicorn等）とアップロードサイズ・認証の見直しを行ってください。
- アップロードされたファイルは処理後に一時ディレクトリ(`_uploads/`)から削除されます。生成された結果ファイル(`_outputs/`)は都度上書きされないので、長期運用する場合は定期的に削除してください。
