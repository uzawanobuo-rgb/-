# 価格一括更新ファイル × 【全国】おためし入居キャンペーン 同期Webツール（ローカル起動）

社内の他の人にも使ってもらえるよう、公開サーバーではなく「各自のPCでダブルクリックして起動する」方式にしています（VBAマクロを保持したままにするにはPython実行環境が必要なため、かつ社外への公開を避けるため）。

## 起動方法（初めての人向け）

事前にPython 3が必要です（未インストールの場合は https://www.python.org/downloads/ から。Windowsはインストール時に**「Add python.exe to PATH」に必ずチェック**）。

1. `webtool` フォルダごとPCにコピー（または `git clone` してこのフォルダに移動）
2. **Windows**: `起動.bat` をダブルクリック
   **Mac**: `起動.command` をダブルクリック（初回は右クリック→「開く」が必要な場合があります）
3. 自動でブラウザが開きます（開かない場合は http://127.0.0.1:5000/ を手動で開いてください）
4. 使い終わったら、開いた黒い画面（ターミナル）を閉じれば終了します

初回は自動的に必要なパッケージをインストールするため少し時間がかかります。2回目以降は数秒で起動します。

### コマンドラインで起動する場合

```bash
cd cp-otm-sheet-sync/webtool
pip install -r requirements.txt
python app.py
```

## 使い方

1. 【全国】おためし入居キャンペーンファイル(.xls)・価格一括更新ファイル(.xlsm)・プラン・キャンペーン一覧(.csv、http://magi2.atinn.jp/SimpleOutputCsv/plan からダウンロード)の3つをそれぞれ選択
2. 「同期を実行」をクリック
3. マッチ結果（新規依頼・期間変更・あいまい一致・更新対象外）が一覧表示される
4. 「更新後のファイルをダウンロード」から結果のxlsmを取得

## 仕組み・注意点

- サーバー側（Python/openpyxl）で処理するため、価格一括更新ファイルのVBAマクロ・条件付き書式・他シート（スペシャル/ロング/CP価格設定シート）はすべて保持されます。ブラウザ完結（JavaScriptのみ）のツールではこれができません。
- `127.0.0.1`（自分のPC内から）のみアクセス可能な設定にしているため、同じPC以外からは開けません。社内ネットワークで共有したい場合は別途相談してください。
- ロジックは `../sync_core.py`（CLI版 `sync_cp_otm.py` と共通）を利用しています。マッチング条件や列の対応を変えたい場合はそちらを編集してください。
- 次の場合、その物件は更新対象外になります（結果画面に別枠表示）：①プラン・キャンペーン一覧CSVで「おためし入居キャンペーン」「おためし入居キャンペーン②」が同一物件に両方存在する場合、②【全国】おためし入居キャンペーンファイルの「登録削除」欄以下に記載されている場合、③①新規依頼で賃料・清掃費の割引率(V・W列)が空欄の場合。
- アップロードされたファイルは処理後に一時ディレクトリ(`_uploads/`)から削除されます。生成された結果ファイル(`_outputs/`)は都度上書きされないので、長期運用する場合は定期的に削除してください。
- 常時稼働する社内サーバーとして公開したい場合は、本番用WSGIサーバー（gunicorn等）・認証・アップロードサイズ制限の見直しが別途必要です。
