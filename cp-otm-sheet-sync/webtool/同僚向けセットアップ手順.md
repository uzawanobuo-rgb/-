# 価格一括更新ファイル×【全国】おためし入居キャンペーン 同期ツール セットアップ手順

これは「価格一括更新ファイル」に「【全国】おためし入居キャンペーンファイル」の内容を反映するツールです。以下の手順でご自身のPCで使えるようになります。

---

## ステップ1：フォルダを受け取る

送られてきたZIPファイル（`cp-otm-sheet-sync.zip` など）を、デスクトップなど分かりやすい場所に展開（解凍）してください。

- Windows：ZIPファイルを右クリック →「すべて展開」
- Mac：ZIPファイルをダブルクリックすると自動で展開されます

展開すると `cp-otm-sheet-sync` というフォルダができます。その中に `webtool` フォルダが入っていればOKです。

## ステップ2：Pythonをインストールする（すでに入っている場合は不要）

1. https://www.python.org/downloads/ を開く
2. 「Download Python」ボタンからインストーラーをダウンロードして実行
3. **【Windowsの方は重要】** インストール画面の一番下にある **「Add python.exe to PATH」に必ずチェック**を入れてから「Install Now」をクリック
4. インストール完了後、念のためPCを再起動

すでにPythonを使ったことがある方はこの手順は不要です。

## ステップ3：ツールを起動する

`cp-otm-sheet-sync` → `webtool` フォルダを開きます。

### Mac の方

`起動.command` をダブルクリックしてください。「開発元が未確認のため開けません」と出たら → `起動.command` を**右クリック**→「開く」→ 出てきたダイアログで「開く」をクリック（初回のみ）。

### Windows の方

`起動.bat` はPCのセキュリティ設定（スマートアプリコントロール等）によりブロックされて動かないことがあります。その場合、以下の**手動起動**の方が確実です（一度警告が出て回避できない場合は、最初からこちらをお使いください）。

1. `webtool` フォルダの中が表示されている状態で、エクスプローラーの**アドレスバー**（フォルダのパスが表示されている場所）をクリックして空にし、`cmd` と入力してEnter
   → そのフォルダの場所でコマンド画面（黒い画面）が開きます
2. 開いた画面に、以下を**まとめて1行としてコピーして貼り付け**、Enter

   ```
   python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt && python app.py
   ```

3. 初回は準備（数十秒〜数分）に時間がかかります。終わると自動でブラウザが開き、ツールの画面が表示されます

2回目以降は、この画面を再度開いて次のコマンドだけ実行すれば起動できます（venv作成・インストール済みのため速いです）。

```
venv\Scripts\activate && python app.py
```

まず`起動.bat`のダブルクリックを試してみて、警告が出て進めない場合にこの手動手順に切り替える、という流れで大丈夫です。

## ステップ4：使う

1. 開いたブラウザ画面で、【全国】おためし入居キャンペーンファイル(.xls)と価格一括更新ファイル(.xlsm)をそれぞれ選択
2. 「同期を実行」をクリック
3. マッチ結果の一覧が表示されるので確認
4. 「更新後のファイルをダウンロード」をクリックして完了

使い終わったら、開いたままの黒い画面（ターミナル）を閉じればツールも終了します。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `起動.bat`で「スマートアプリコントロールが安全でないため...」と出て進めない | ステップ3の「手動起動」に切り替えてください（.batファイル自体を実行しない方法なのでブロックされません） |
| 「Pythonが見つかりません」「Python was not found」と出る | 実際にはPythonが入っていません。設定→アプリ→インストールされているアプリで「Python」を検索し、なければ https://www.python.org/downloads/ からインストール（**「Add python.exe to PATH」に必ずチェック**）。既にある場合は 設定→アプリ→詳細なアプリ設定→アプリ実行エイリアス で「python.exe」「python3.exe」をオフに。変更後はコマンド画面を閉じて開き直してください |
| `venv\Scripts\activate`で「指定されたパスが見つかりません」 | `webtool`フォルダの中でコマンド画面を開けているか確認してください（一つ上の`cp-otm-sheet-sync`フォルダで開いていませんか？） |
| 起動時に固まったまま進まない | 社内ネットワークやセキュリティソフトがインターネット接続をブロックしている可能性があります。初回起動時だけ、必要な部品をインターネットからダウンロードします |
| ブラウザが自動で開かない | 手動で `http://127.0.0.1:5000/` を開いてください |
| それでも解決しない | 手順を実行した際の画面（黒い画面の表示内容）のスクリーンショットを添えて連絡してください |
