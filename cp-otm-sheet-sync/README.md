# CP × OTM シート同期結果

CP価格一括更新ファイルの「おためし」シートに、OTM（【全国】おためし入居キャンペーン）ファイルの最新シート（`260804`＝2026-08-04）の内容を反映しました。

## マッピング

### ①新規依頼（OTM:M列 ＝ CP:D列 でVLOOKUP）
| 項目 | OTM列 | CP列 |
|---|---|---|
| 期間開始日 | N列 | AG列（入居可能開始日） |
| 期間終了日 | P列 | AH列（入居可能終了日） |
| 賃料 | V列 | Z列（賃料）※数式 `=N{行}*(1-{割引率}%)` で記載（例：`=N936*(1-50%)`。定価Nから割引率分を引いた実額を自動計算） |
| 清掃費 | W列 | AF列（割引率）※数値0.75などに変換して記載（セルが0%書式のため） |
| 更新対象マーク | - | AK列に「○」 |

### ②期間変更（OTM:A列 ＝ CP:D列 でVLOOKUP）
| 項目 | OTM列 | CP列 |
|---|---|---|
| 期間開始日 | B列 | AG列（入居可能開始日） |
| 期間終了日 | D列 | AH列（入居可能終了日） |
| 賃料 | CP:R列（自身の現行おためし価格） | Z列（賃料） |
| 更新対象マーク | - | AK列に「○」 |

※ご指定いただいたAP/AD/AJ列は「おためし」シートには実在しない、または既存の別データ（現：価格・最終退去日）が入っている列だったため、実際のシート構成に合わせてAK/Z/AFに変更しています（チャットでのやり取りで確認済み）。

## 結果

- ①新規依頼: 18件中 **18件マッチ** → ○を記載
- ②期間変更: 2件中 **2件マッチ** → ○を記載

VLOOKUPはまず完全一致で照合し、一致しない場合はCP側プラン名の先頭記号（◇◆■□●☆）を除いた名前で再照合するフォールバックを追加しています（OTM側で記号の入力漏れがあるケースに対応。CP側の記号が正のため、CP側は変更せずマッチングのみ緩和）。この結果、以下の2件も更新されました。

- `アットイン中野9-2`（CP側は「□アットイン中野9-2」）→ 記号なしで再照合しマッチ
- `アットイン武蔵小杉2-1`（CP側は「◇アットイン武蔵小杉2-1」）→ 記号なしで再照合しマッチ

先頭記号を除いた名前が複数のCP行と一致してしまう「あいまい一致」が発生した場合は自動更新せず、スクリプトの実行ログに候補行を出力します（今回は該当なし）。

## 注意事項

- このセッションのLibreOffice環境が正常に動作せず（どのファイルも読み込めない状態）、自動フォーマチュラ再計算・検証ができませんでした。書き込んだ数式・値については手計算でExcel/Calcの数式評価ルールに基づきエラー（#VALUE!等）が発生しないことを確認していますが、実際にExcelで開いて最終確認をお願いします。
- Z列（賃料）の数式 `=N*(1-割引率%)` は、ユーザー確認済みの解釈（「60%OFF」＝定価の60%引き＝定価の40%）に基づいています。
- 「スペシャル」「ロング」「CP価格設定シート」の各シートは変更していません。
- マクロ（VBA）は保持されています。
