# CP × OTM シート同期結果

CP価格一括更新ファイルの「おためし」シートに、OTM（【全国】おためし入居キャンペーン）ファイルの最新シート（`260804`＝2026-08-04）の内容を反映しました。

## マッピング

### ①新規依頼（OTM:M列 ＝ CP:D列 でVLOOKUP）
| 項目 | OTM列 | CP列 |
|---|---|---|
| 期間開始日 | N列 | AG列（入居可能開始日） |
| 期間終了日 | P列 | AH列（入居可能終了日） |
| 賃料 | V列 | Z列（賃料）※「50%OFF」→「50%」に変換して記載 |

| 更新対象マーク | - | AK列に「○」 |

### ②期間変更（OTM:A列 ＝ CP:D列 でVLOOKUP）
| 項目 | OTM列 | CP列 |
|---|---|---|
| 期間開始日 | B列 | AG列（入居可能開始日） |

※ご指定いただいたAP/AD/AJ列は「おためし」シートには実在しない、または既存の別データ（現：価格・最終退去日）が入っている列だったため、実際のシート構成に合わせてAK/Z/AFに変更しています（チャットでのやり取りで確認済み）。

## 結果

- ①新規依頼: 18件中 **17件マッチ** → ○を記載
  - 未マッチ: `アットイン中野9-2`（OTM側は「□アットイン中野9-2」、CP側の表記と記号が一致せず、意図的に更新していません）
- ②期間変更: 2件中 **1件マッチ**（アットイン浅草橋4）→ ○を記載
  - 未マッチ: `アットイン武蔵小杉2-1`（OTM側は無印、CP側は「◇アットイン武蔵小杉2-1」で記号が一致せず）

未マッチの2件は、CP側のプラン名の記号（◇や□など）とOTM側の物件名表記が完全一致しないため、意図的な厳密VLOOKUPの結果として更新していません。手動でご確認のうえ、プラン名を統一するか個別に転記してください。
