# 名刺発注管理システム 5選（社内検討用）

作成日：2026-11-11
目的：自社の従業員の名刺発注（申請 → 承認 → 印刷 → 納品）をまとめて管理できるサービスを比べる。

> ここに書いた料金・機能は、各社の掲載情報やレビューサイト（ITreview など）をもとにまとめたものです。
> 料金・条件は変わることがあるので、導入前に必ず各社の公式資料・見積もりで確認してください。
> 「要確認」と書いた項目は、公開情報では確かめられなかったものです。

## 1. NAMEROOM（ネイムルーム）／株式会社山櫻

- 名刺の発注・承認・管理をクラウド上でまとめて行う法人向けサービス。累計導入 2,500社以上（公表値）。
- **連携が強い**：調達・購買システムとの連携実績、SSO 連携、人事マスタ連携に対応。SmartHR Plus のアプリとしても提供。
- 申請すると申請番号が自動で振られ、発注履歴から確認できる。履歴はテキストファイルでダウンロード可（保存期間 13か月）。
- 権限（一般・代理申請者・承認者・管理者）ごとに作れる名刺数に上限がある。
- **料金**：企業規模・人数に応じたプラン制。公開価格なし → 見積もりが必要。
- **気をつけること**：料金が見えにくい。小規模だと割高になる可能性。

## 2. Sansan名刺メーカー／Sansan株式会社

- 名刺の作成から発注まで一括で行えるサービス。社員が発注すると担当者に通知が届き、内容を確認して承認する流れ。
- **紙の名刺とオンライン名刺の両方**を作れる。
- Google Workspace や Microsoft Teams から使える。Sansan（名刺管理）を契約していなくても利用可。
- 自社指定の印刷会社を使い続けたい場合向けに、印刷データだけを出力するプランもある。
- **料金**：1ユーザー 年1,500円（税別）。1ユーザーあたり年1箱（100枚）の発注が含まれる。超えた分は見積もり。
- **気をつけること**：ユーザー数に比例して年額がかかる。名刺をあまり刷らない社員が多いと割高。

## 3. クラウド法人名刺（マヒト法人名刺）／株式会社マヒト

- 名刺の作成から発注まで Web 上で完結。最短当日発送。
- **部署ごとの承認フロー**、ユーザーごとの権限（発注・承認・管理）を設定できる。
- 社員情報の自動反映、配送先・請求先の事前登録、文字量に合わせたレイアウト自動調整。
- **Excel で一括発注**でき、他社システムからの乗り換えがしやすい。
- **料金**：システム利用料 0円。印刷代と送料のみ。ユーザー数無制限のプランあり。
- 評価：ITreview 総合満足度 4.5（レビュー 29件）。累計 97,000社以上（公表値）。
- **気をつけること**：初期設定（デザイン登録など）の費用の有無は見積もりで確認。

## 4. 印刷部ドットネット／株式会社オンデオマ

- デザイン編集・発注・納品先設定・請求管理まで Web 上で行える。専用ソフト不要（PC・タブレットのブラウザで操作）。
- **最大3段階の承認フロー**。
- **人事異動時は Excel で一括登録・一括発注**できる。増刷は最短 20秒で発注完了（公表値）。
- **料金**：システム利用料・月額費用・保守費 0円。名刺単価・送料は見積もり。
- 導入 5,000社以上（公表値）。
- **気をつけること**：名刺1箱あたりの単価を他社と比べること。

## 5. Biz名刺／株式会社エクストラハンズ

- 法人向けの名刺発注サービス。
- **料金**：初期費用・月額基本料 0円、印刷した分だけの支払い（運営側の説明）。
- **気をつけること**：承認フローや一括発注の細かい仕様は公開情報では確かめられず。資料請求で確認が必要。

## 選ぶときのチェックポイント

1. **承認フロー**：何段階必要か。部署・拠点ごとに承認者を分けたいか。
2. **人事異動への対応**：4月・10月などの一斉異動を Excel 一括登録で処理できるか。
3. **社内システムとの連携**：SSO（Google / Microsoft）、人事システム（SmartHR など）、購買システム。
4. **費用の形**：
   - ユーザー課金型（例：Sansan名刺メーカー）→ 人数 × 年額
   - 印刷代のみ型（例：マヒト、印刷部ドットネット、Biz名刺）→ 刷った分だけ
5. **名刺の単価・送料・納期**：1人100枚 × 年◯回 で年間コストを試算して比べる。
6. **オンライン名刺**が必要か（必要なら Sansan名刺メーカーが有力）。
7. **請求のまとめ方**：部署別・拠点別の請求書を出せるか。

## ざっくりおすすめ

- **費用を一番抑えたい** → クラウド法人名刺（マヒト）か 印刷部ドットネット
- **人事異動が多い** → 印刷部ドットネット
- **SSO・人事データと連携したい（大きめの会社）** → NAMEROOM
- **紙とオンライン名刺の両方を使いたい／Google・Teams 中心** → Sansan名刺メーカー
- **まず小さく試したい** → Biz名刺 または マヒト

## 次の一手

1. 社員数・年間の発注回数・承認ルートを書き出す
2. 上の 5社のうち 2〜3社に資料請求・見積もり（同じ条件で：例「社員◯名、1人100枚、年2回」）
3. 無料トライアルやデモで、申請〜承認の画面を実際に触って比べる
